# CodePTIT - Python

Repository tổng hợp các bài tập **Python** mình đã thực hiện trên **CodePTIT** trong quá trình học tập và luyện tập lập trình.

Các bài tập được phân chia theo từng chủ đề để dễ theo dõi và ôn tập.

## 📚 Các chủ đề

* **Biến và kiểu dữ liệu đơn giản**
* **Câu lệnh rẽ nhánh**
* **Danh sách**
* **Đối tượng**
* **Từ điển**

## 🎯 Mục đích

* Lưu trữ các bài tập Python đã giải trên CodePTIT.
* Hệ thống hóa kiến thức theo từng chủ đề.
* Theo dõi quá trình học tập và luyện tập Python.
* Dễ dàng xem lại lời giải khi cần.

> Repository phục vụ mục đích học tập và luyện tập cá nhân.
